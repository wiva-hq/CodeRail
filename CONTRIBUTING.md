# Contributing

Thanks for your interest in CodeRail.

**Issues are welcome; pull requests aren't accepted.** CodeRail is open source so you can read it,
run it, host it and change your own copy, but its development happens in one place, and this
repository has pull requests turned off.

The most useful things you can do:

- **Report a bug** with the [bug report form](https://github.com/wiva-hq/CodeRail/issues/new?template=bug_report.yml):
  what happened, how to make it happen again, versions and logs (with anything private removed).
- **Suggest an idea** with the [idea form](https://github.com/wiva-hq/CodeRail/issues/new?template=feature_request.yml):
  start from the problem you have, not only the solution.
- **Report a security problem privately**, never as an issue; see [SECURITY.md](SECURITY.md).

If you've fixed something in your own copy, describe the fix in an issue (a snippet or a link to your
fork's commit is fine); it may be taken in.
